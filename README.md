## Описание
Учебная веб-страница туристического блога. В проекте используются семантические элементы HTML5 (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`), локальные изображения, `figure`/`figcaption`, даты через `time`, форма подписки, списки и внешний CSS3-файл.

## Структура
`index.html` — HTML-разметка страницы.
`css/style.css` — оформление страницы.
`images/` — локальные изображения проекта.

## Запуск
Откройте `index.html` в браузере.
